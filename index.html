Admin Portal CLQ Mamuju memerlukan layar yang lebih besar untuk menampilkan data dengan baik. Harap buka halaman ini melalui Laptop atau Komputer Anda.

CLQ MAMUJU

Selamat Datang di Admin Portal CLQ Mamuju

Silakan pilih menu di atas untuk mulai mengelola data:

Dashboard

Berisi submenu monitoring posisi target kunjungan harian, distribusi tugas, pembatalan tugas, pindah kelolaan, laporan kunjungan, dan manajemen user.

Update Rindeb

Menu update Rindeb harian dengan data dari SharePoint. Mendukung fitur impor file Excel/CSV, inspeksi otomatis, serta sinkronisasi kelolaan debitur.

Update Bayar

Menu update data debitur yang melakukan pembayaran. Data diperbarui secara berkala dari SharePoint dalam format CSV.

Monitor Live

Menu untuk memantau lokasi pergerakan, aktivitas, dan progres tim penagihan secara real-time.
